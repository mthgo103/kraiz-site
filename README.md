# kraiz-site

الموقع التعريفي لمجموعة كريز الصناعية — Company introduction and product catalog website for Kraiz Industrial Group.

Static site (HTML/CSS/JS) published via GitHub Pages: https://mthgo103.github.io/kraiz-site/

- `index.html` — Arabic home (default)
- `products.html`, `plastic-products.html`, `metal-products.html` — catalog pages
- `en/` — English versions
- `styles/main.css` — shared stylesheet
- `assets/` — logo, hero and product images
